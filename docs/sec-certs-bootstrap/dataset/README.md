# Dataset drop folder

Download the current sec-certs **Common Criteria** JSON dump into this folder.

- Scope: CC only (ignore FIPS for this exercise).
- Use a freshly downloaded copy — do not assume any older dataset elsewhere on
  disk is current.
- After downloading, note the filename and the download date at the top of
  `../decision-log.md` so the bootstrap is reproducible.

This folder is intentionally empty until you drop the dataset in.

# ADR-0005: Governance, citation and contribution infrastructure deferred

| | |
|---|---|
| **Status** | Accepted; revisit at 1.0 |
| **Former record** | DECISIONS S5 |

## Context

These were researched and deliberately not added: `CITATION.cff`, `CONTRIBUTING.md`, `GOVERNANCE.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, Zenodo DOI minting, SWHID, per-file SPDX headers, OpenSSF badge and Scorecard.

## Decision

Add none of them yet. The repository has one maintainer, no outside contributors and no release before 1.0, so none of them has a use yet.

## Consequences

The README's contribution notes are the only guidance. Revisit together with ADR-0002.
